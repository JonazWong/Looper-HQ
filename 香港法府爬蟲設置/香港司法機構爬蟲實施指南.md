## 5分鐘快速開始

### 環境要求

- **Python 3.8+** 或 **Node.js 18+**
- **互聯網連接**
- **SQLite3** (已內置) 或 **PostgreSQL**

### 快速安裝 (Python)

```bash
# 1. 克隆或下載爬蟲程式碼
cd /your/project/directory

# 2. 建立虛擬環境
python3 -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate

# 3. 安裝依賴
pip install requests beautifulsoup4 lxml schedule

# 4. 執行一次爬蟲
python3 hk-judiciary-crawler.py --mode once

# 5. 檢查結果
sqlite3 judiciary_cases.db "SELECT COUNT(*) FROM cases;"
```

### 快速安裝 (與 Looper-HQ 整合)

```bash
# 1. 在 Looper-HQ 根目錄執行
cp looper-hq-judiciary-adapter.ts services/crawlers/

# 2. 安裝套件
pnpm add axios cheerio

# 3. 更新 package.json
pnpm exec -- node -e "console.log('系統準備就緒')"

# 4. 執行爬蟲
pnpm crawler:judiciary

# 5. 查看結果
pnpm db:studio  # 在 Prisma Studio 中檢查 PublicCase 表
```

## 詳細安裝步驟

### 步驟 1: 準備環境

```bash
# 檢查 Python 版本
python3 --version  # 應為 3.8+

# 建立專案目錄
mkdir -p /opt/judiciary-crawler
cd /opt/judiciary-crawler

# 建立虛擬環境
python3 -m venv venv
source venv/bin/activate
```

### 步驟 2: 安裝依賴

```bash
# 升級 pip
pip install --upgrade pip

# 安裝所有必要套件
pip install -r requirements.txt

# 驗證安裝
python3 -c "import requests, bs4, schedule; print('✅ 所有依賴已安裝')"
```

### 步驟 3: 配置爬蟲

```bash
# 複製爬蟲程式碼
cp hk-judiciary-crawler.py .

# 建立配置檔案
cat > .env << EOF
JUDICIARY_DB=./judiciary_cases.db
CRAWLER_LOG=./crawler.log
CRAWLER_TIMEOUT=15000
CRAWLER_MAX_RETRIES=3
EOF

# 設置日誌目錄
mkdir -p logs
```

### 步驟 4: 運行初始爬蟲

```bash
# 執行一次爬蟲 (約 5-10 分鐘)
python3 hk-judiciary-crawler.py --mode once

# 監控進度
tail -f crawler.log
```

### 步驟 5: 設置排程 (Linux/Mac)

```bash
# 建立 systemd 計時器 (Linux)

# 1. 建立服務檔案
sudo tee /etc/systemd/system/judiciary-crawler.service > /dev/null << 'EOF'
[Unit]
Description=Hong Kong Judiciary Daily Crawler
After=network-online.target
Wants=network-online.target

[Service]
Type=oneshot
User=crawler
WorkingDirectory=/opt/judiciary-crawler
Environment="PATH=/opt/judiciary-crawler/venv/bin"
ExecStart=/opt/judiciary-crawler/venv/bin/python3 hk-judiciary-crawler.py --mode once
StandardOutput=journal
StandardError=journal
EOF

# 2. 建立計時器檔案
sudo tee /etc/systemd/system/judiciary-crawler.timer > /dev/null << 'EOF'
[Unit]
Description=Run Hong Kong Judiciary Crawler Daily at 2 AM

[Timer]
OnCalendar=*-*-* 02:00:00
Persistent=true

[Install]
WantedBy=timers.target
EOF

# 3. 啟用並啟動計時器
sudo systemctl daemon-reload
sudo systemctl enable judiciary-crawler.timer
sudo systemctl start judiciary-crawler.timer

# 4. 檢查計時器狀態
sudo systemctl status judiciary-crawler.timer
systemctl list-timers judiciary-crawler.timer
```

### 步驟 5b: 設置排程 (macOS)

```bash
# 使用 launchd (macOS)

# 1. 建立 LaunchAgent
mkdir -p ~/Library/LaunchAgents
cat > ~/Library/LaunchAgents/com.judiciary.crawler.plist << 'EOF'
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Label</key>
    <string>com.judiciary.crawler</string>
    <key>ProgramArguments</key>
    <array>
        <string>/usr/local/bin/python3</string>
        <string>/opt/judiciary-crawler/hk-judiciary-crawler.py</string>
        <string>--mode</string>
        <string>once</string>
    </array>
    <key>StartCalendarInterval</key>
    <dict>
        <key>Hour</key>
        <integer>2</integer>
        <key>Minute</key>
        <integer>0</integer>
    </dict>
    <key>StandardOutPath</key>
    <string>/var/log/judiciary-crawler.log</string>
    <key>StandardErrorPath</key>
    <string>/var/log/judiciary-crawler.err</string>
</dict>
</plist>
EOF

# 2. 載入 LaunchAgent
launchctl load ~/Library/LaunchAgents/com.judiciary.crawler.plist

# 3. 檢查狀態
launchctl list | grep judiciary
```

### 步驟 5c: 設置排程 (Windows)

```batch
REM 使用 Windows 工作排程器

REM 1. 開啟工作排程器
REM   開始 → 搜尋 "工作排程器"

REM 2. 建立基本工作
REM   動作 → 建立工作

REM 3. 設置觸發程序
REM   時間表: 每日 02:00

REM 4. 設置操作
REM   程式/指令碼: C:\Python312\python.exe
REM   引數: C:\judiciary-crawler\hk-judiciary-crawler.py --mode once

REM 5. (可選) 使用 PowerShell 指令碼自動化
powershell -Command "& {
    $trigger = New-ScheduledTaskTrigger -Daily -At 2:00AM
    $action = New-ScheduledTaskAction -Execute 'C:\Python312\python.exe' -Argument 'C:\judiciary-crawler\hk-judiciary-crawler.py --mode once'
    Register-ScheduledTask -TaskName 'JudiciaryCrawler' -Trigger $trigger -Action $action -RunLevel Highest
}"
```

```bash

EOF
```

### 測試 3: 資料完整性檢查

```bash
# 檢查各法院是否都有案件
sqlite3 judiciary_cases.db << 'EOF'
.mode column
.headers on
SELECT 
    court,
    COUNT(*) as case_count,
    MIN(hearing_date) as oldest_date,
    MAX(hearing_date) as newest_date
FROM cases
GROUP BY court
ORDER BY case_count DESC;
EOF

# 預期結果: 所有主要法院都應有案件
```

### 測試 4: 去重機制驗證

```bash
# 檢查重複情況
sqlite3 judiciary_cases.db << 'EOF'
SELECT case_number, COUNT(*) as duplicate_count 
FROM cases 
GROUP BY case_number 
HAVING duplicate_count > 1 
LIMIT 10;
EOF

# 預期結果: 無重複案件
```

### 測試 5: 定時排程測試

## 常見問題排查

### 問題: "Module not found" 錯誤

```bash
# 解決: 確認虛擬環境已啟用
source venv/bin/activate  # 或 source venv/bin/activate.fish

# 檢查已安裝的包
pip list | grep -E "requests|beautifulsoup"
```

### 問題: 連接超時

```bash
# 解決: 增加超時時間
python3 hk-judiciary-crawler.py --mode once --timeout 30000

# 或在代碼中修改:
self.timeout = 30  # 秒
```

### 問題: 資料庫鎖定

```bash
# 解決: 檢查已打開的連接
sqlite3 judiciary_cases.db ".open"

# 如需恢復:
rm judiciary_cases.db
python3 hk-judiciary-crawler.py --mode once  # 重新建立
```

### 問題: 爬蟲無案件結果

```bash
# 診斷:
python3 test-crawler.py  # 檢查連接

# 啟用詳細日誌:
# 在爬蟲程式碼中改為
logging.basicConfig(level=logging.DEBUG)

# 檢查 HTML 結構是否改變
curl -s "https://e-services.judiciary.hk/dcl/index.jsp?lang=tc&mode=view&date=latest&court=DC" | head -200
```

## 生產監控命令

### 每日檢查清單

```bash
#!/bin/bash
# 每日檢查腳本 (daily-check.sh)

echo "=== 爬蟲健康檢查 ==="

# 1. 檢查最後執行時間
LAST_RUN=$(sqlite3 judiciary_cases.db "SELECT MAX(crawled_date) FROM cases;")
echo "最後執行時間: $LAST_RUN"

# 2. 檢查今日案件數
TODAY=$(date +%Y-%m-%d)
COUNT=$(sqlite3 judiciary_cases.db "SELECT COUNT(*) FROM cases WHERE crawled_date LIKE '$TODAY%';")
echo "今日新增案件: $COUNT"

# 3. 檢查錯誤日誌
ERRORS=$(grep "ERROR" crawler.log | tail -5)
if [ -z "$ERRORS" ]; then
    echo "✅ 無錯誤"
else
    echo "⚠️  最近錯誤:"
    echo "$ERRORS"
fi

# 4. 檢查資料庫大小
SIZE=$(du -h judiciary_cases.db | cut -f1)
echo "資料庫大小: $SIZE"

echo "檢查完成"
```

### 週期性維護

```bash
# 每週清理 (weekly-maintenance.sh)

# 1. 刪除 90 天前的舊案件
sqlite3 judiciary_cases.db "DELETE FROM cases WHERE crawled_date < datetime('now', '-90 days');"

# 2. 最佳化資料庫
sqlite3 judiciary_cases.db "VACUUM;"

# 3. 重新建立索引
sqlite3 judiciary_cases.db "REINDEX;"

# 4. 備份資料庫
cp judiciary_cases.db "judiciary_cases.db.backup.$(date +%Y%m%d)"

echo "維護完成"
```
