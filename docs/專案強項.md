## 7. 📊 自動化公開案件追蹤

**法律情報自動收集**

### 爬蟲系統架構
```
GitHub Actions (cron: 0 18 * * * = 2am HKT)
       ↓
RSS 新聞爬蟲
       ↓
[SCMP] [RTHK] [Ming Pao] [HK01]
       ↓
案件解析與分類
       ↓
重複檢測 (source + externalId)
       ↓

       ↓
```

### 特色功能
- **定時執行**：每日凌晨 2 點 HKT
- **智能去重**：unique constraint 防止重複
- **來源黑名單**：過濾低質量來源
- **錯誤容忍**：XML 解析錯誤處理
- **手動觸發**：`pnpm crawler:all`

## 10. 🌍 國際化 (i18n) 原生支援

**next-intl 深度整合**

- **URL 策略**：`/[locale]/path`
- **預設語言**：繁體中文 (zh)
- **支援語言**：繁中、英文
