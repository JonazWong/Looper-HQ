# 香港司法機構案件數據自動抓取系統 - 完整實現指南

## 執行摘要

本指南提供了一套完整的解決方案，用於每日自動抓取香港司法機構（高等法院、區域法院、初級法院等）的案件內容及更新，存儲到您的法律專案數據庫。系統採用 Node.js + Puppeteer（或 Cheerio）、定時任務調度、增量更新等技術，確保高效、可靠、合規的數據抽取。

**系統亮點**:
- ✅ 自動每日運行，無需手動干預
- ✅ 支持多個司法機構網站
- ✅ 增量更新（僅抓新增或更改的案件）
- ✅ 錯誤自動重試 & 監控告警
- ✅ 完全合規（遵守 robots.txt、速率限制）
- ✅ 與 Next.js + Prisma 無縫集成

### 1.3 合規與法律考量

#### ⚠️ 重要法律事項

**1. Robots.txt 遵守**
```
香港司法機構 robots.txt:
https://www.judiciary.hk/robots.txt

Must-follow 規則:
- User-Agent: 所有爬蟲
- Disallow: /admin, /internal
- Allow: /en/services/opinions
- Crawl-delay: 2 (每個請求間隔 2 秒)
```

**2. 速率限制**
- 建議每個請求間隔 2-3 秒
- 每小時不超過 100 請求
- User-Agent 標識為合法爬蟲

**3. 著作權**
- ✅ 司法判決書為公開文件，可自由使用
- ⚠️ 但須清楚標註來源（司法機構）
- ✅ 個人使用、教育、研究無限制
- ⚠️ 商業使用需了解 T&C

**4. 隱私法規**
- 案件涉及個人信息時需謹慎
- 法院有時會匿名當事人
- 遵守香港《個人資料私隱條例》

### 2.2 技術棧選擇

#### 爬蟲方案對比

| 方案 | 優點 | 缺點 | 適用場景 |
|------|------|------|---------|
| **Puppeteer** | 支持 JS 渲染、自動化強 | 資源消耗高、速度慢 | 複雜動態頁面 |
| **Cheerio** | 輕量、快速、易上手 | 無法執行 JavaScript | 靜態 HTML 頁面 |
| **Playwright** | 跨瀏覽器、穩定 | 依賴較重 | 長期穩定爬蟲 |
| **Axios + BeautifulSoup** | 簡單輕量 | 不支持 JS 渲染 | 簡單爬蟲 |

**推薦**: Cheerio (香港司法網站多為靜態頁面) + Axios

#### 技術棧組成


## 第三部分：爬蟲實現代碼

### 3.1 基礎爬蟲模組

```typescript
// lib/scrapers/judiciary-scraper.ts

import axios, { AxiosInstance } from "axios";
import * as cheerio from "cheerio";
import crypto from "crypto";
import { logger } from "@/lib/logger";

interface CaseData {
  caseNumber: string;
  caseTitle: string;
  court: string;
  category: string;
  filingDate?: Date;
  dateOfJudgment?: Date;
  judge?: string;
  summary?: string;
  fullText?: string;
  documentUrl?: string;
  status: string;
  parties: Array<{ name: string; role: string }>;
  sourceUrl: string;
  contentHash: string;
}

export class HKJudiciaryScraper {
  private client: AxiosInstance;
  private readonly baseUrl = "https://www.judiciary.hk";
  private readonly delayMs = 2000; // 遵守 robots.txt 的 2 秒延遲

  constructor() {
    this.client = axios.create({
      baseURL: this.baseUrl,
      timeout: 10000,
      headers: {
        'User-Agent': 'Mozilla/5.0 (compatible; HKLegal-Scraper/1.0; +http://yourdomain.com/scraper-info)',
        'Accept': 'text/html,application/xhtml+xml',
        'Accept-Language': 'zh-HK,zh;q=0.9,en;q=0.8',
      },
    });
  }

  /**
   * 延遲函數，用於速率限制
   */
  private async delay(ms: number): Promise<void> {
    return new Promise(resolve => setTimeout(resolve, ms));
  }

  /**
   * 計算內容的 MD5 哈希（用於去重）
   */
  private calculateContentHash(content: string): string {
    return crypto.createHash('md5').update(content).digest('hex');
  }

  /**
   * 抓取高等法院判決書列表
   */
  async scrapeCourtOfAppeal(): Promise<CaseData[]> {
    try {
      logger.info("開始抓取高等法院案件...");
      
      const url = "/en/services/opinions/index.html";
      await this.delay(this.delayMs);
      
      const response = await this.client.get(url);
      const $ = cheerio.load(response.data);
      
      const cases: CaseData[] = [];
      
      // 假設案件列表在 table 中
      $('table tbody tr').each((index, element) => {
        try {
          const $row = $(element);
          
          const caseNumber = $row.find('td:nth-child(1)').text().trim();
          const caseTitle = $row.find('td:nth-child(2)').text().trim();
          const dateStr = $row.find('td:nth-child(3)').text().trim();
          const judge = $row.find('td:nth-child(4)').text().trim();
          const linkHref = $row.find('a').attr('href');
          
          if (!caseNumber) return;
          
          const caseData: CaseData = {
            caseNumber,
            caseTitle,
            court: "Court of Appeal",
            category: "Civil Appeal",
            dateOfJudgment: this.parseDate(dateStr),
            judge,
            documentUrl: linkHref ? `${this.baseUrl}${linkHref}` : undefined,
            status: "Decided",
            parties: this.extractParties(caseTitle),
            sourceUrl: `${this.baseUrl}${url}`,
            contentHash: this.calculateContentHash(caseNumber + caseTitle),
          };
          
          cases.push(caseData);
        } catch (error) {
          logger.warn(`解析案件行失敗: ${error}`);
        }
      });
      
      logger.info(`成功抓取 ${cases.length} 個高等法院案件`);
      return cases;
    } catch (error) {
      logger.error(`抓取高等法院失敗: ${error}`);
      throw error;
    }
  }

  /**
   * 抓取區域法院案件
   */
  async scrapeDistrictCourt(): Promise<CaseData[]> {
    try {
      logger.info("開始抓取區域法院案件...");
      
      const url = "/en/services/court_cases_information/index.html";
      await this.delay(this.delayMs);
      
      const response = await this.client.get(url);
      const $ = cheerio.load(response.data);
      
      const cases: CaseData[] = [];
      
      $('div.case-item').each((index, element) => {
        try {
          const $item = $(element);
          
          const caseNumber = $item.find('.case-number').text().trim();
          const caseTitle = $item.find('.case-title').text().trim();
          const dateStr = $item.find('.case-date').text().trim();
          
          if (!caseNumber) return;
          
          const caseData: CaseData = {
            caseNumber,
            caseTitle,
            court: "District Court",
            category: this.determineCaseCategory($item.find('.case-category').text()),
            dateOfJudgment: this.parseDate(dateStr),
            status: "Decided",
            parties: this.extractParties(caseTitle),
            sourceUrl: `${this.baseUrl}${url}`,
            contentHash: this.calculateContentHash(caseNumber + caseTitle),
          };
          
          cases.push(caseData);
        } catch (error) {
          logger.warn(`解析區域法院案件失敗: ${error}`);
        }
      });
      
      logger.info(`成功抓取 ${cases.length} 個區域法院案件`);
      return cases;
    } catch (error) {
      logger.error(`抓取區域法院失敗: ${error}`);
      throw error;
    }
  }

  /**
   * 下載判決書全文（如果可用）
   */
  async downloadDocumentText(documentUrl: string): Promise<string | null> {
    try {
      if (!documentUrl) return null;
      
      await this.delay(this.delayMs);
      const response = await this.client.get(documentUrl);
      
      // 提取文本內容
      const $ = cheerio.load(response.data);
      const text = $('body').text();
      
      return text || null;
    } catch (error) {
      logger.warn(`下載文檔失敗 ${documentUrl}: ${error}`);
      return null;
    }
  }

  /**
   * 日期解析
   */
  private parseDate(dateStr: string): Date | undefined {
    if (!dateStr) return undefined;
    
    try {
      // 支持格式: "15/02/2024", "2024-02-15", "February 15, 2024"
      const date = new Date(dateStr);
      return isNaN(date.getTime()) ? undefined : date;
    } catch {
      return undefined;
    }
  }

  /**
   * 從案件標題提取當事人
   * 例子: "A v B" -> [{ name: "A", role: "Plaintiff" }, { name: "B", role: "Defendant" }]
   */
  private extractParties(caseTitle: string): Array<{ name: string; role: string }> {
    const parties: Array<{ name: string; role: string }> = [];
    
    // 簡單的解析：按 " v " 分割
    const parts = caseTitle.split(/\s+v\s+/i);
    if (parts.length >= 2) {
      parties.push({ name: parts[0].trim(), role: "Plaintiff" });
      parties.push({ name: parts[1].trim(), role: "Defendant" });
    }
    
    return parties;
  }

  /**
   * 確定案件類別
   */
  private determineCaseCategory(categoryText: string): string {
    if (categoryText.includes("Civil")) return "Civil";
    if (categoryText.includes("Criminal")) return "Criminal";
    if (categoryText.includes("Family")) return "Family";
    if (categoryText.includes("Employment")) return "Employment";
    return "Other";
  }
}

export const judiciaryScraper = new HKJudiciaryScraper();
```

```typescript
// lib/services/case-service.ts

import { db } from "@/lib/db";
import { logger } from "@/lib/logger";
import type { CaseData } from "@/lib/scrapers/judiciary-scraper";

export class CaseService {
  /**
   * 檢查案件是否已存在（基於 contentHash 去重）
   */
  async caseExists(contentHash: string): Promise<boolean> {
    const existing = await db.judicaryCase.findFirst({
      where: { contentHash },
    });
    return !!existing;
  }

  /**
   * 批量保存或更新案件
   */
  async saveCases(cases: CaseData[]): Promise<{ created: number; updated: number }> {
    let created = 0;
    let updated = 0;

    for (const caseData of cases) {
      try {
        // 檢查是否已存在
        const existing = await db.judicaryCase.findUnique({
          where: { caseNumber: caseData.caseNumber },
        });

        if (existing && existing.contentHash === caseData.contentHash) {
          // 內容相同，跳過
          continue;
        }

        if (existing) {
          // 更新現有案件
          await db.judicaryCase.update({
            where: { id: existing.id },
            data: {
              caseTitle: caseData.caseTitle,
              summary: caseData.summary,
              fullText: caseData.fullText,
              documentUrl: caseData.documentUrl,
              contentHash: caseData.contentHash,
              updatedAt: new Date(),
            },
          });
          updated++;
        } else {
          // 創建新案件
          const judicaryCase = await db.judicaryCase.create({
            data: {
              caseNumber: caseData.caseNumber,
              caseTitle: caseData.caseTitle,
              court: caseData.court,
              category: caseData.category,
              filingDate: caseData.filingDate,
              dateOfJudgment: caseData.dateOfJudgment,
              judge: caseData.judge,
              summary: caseData.summary,
              fullText: caseData.fullText,
              documentUrl: caseData.documentUrl,
              status: caseData.status,
              sourceUrl: caseData.sourceUrl,
              sourceSite: "judiciary_hk",
              contentHash: caseData.contentHash,
            },
          });

          // 創建當事人記錄
          for (const party of caseData.parties) {
            await db.caseParty.create({
              data: {
                caseId: judicaryCase.id,
                name: party.name,
                role: party.role,
                type: "Individual", // 可基於內容改進
              },
            });
          }

          created++;
        }
      } catch (error) {
        logger.error(`保存案件 ${caseData.caseNumber} 失敗: ${error}`);
        throw error;
      }
    }

    logger.info(`案件保存完成: 新建 ${created}, 更新 ${updated}`);
    return { created, updated };
  }

  /**
   * 記錄爬蟲日誌
   */
  async logScraperRun(
    source: string,
    status: "success" | "failed" | "partial",
    stats: { total: number; created: number; updated: number; errors?: string }
  ) {
    await db.scraperLog.create({
      data: {
        source,
        status,
        totalCases: stats.total,
        newCases: stats.created,
        updatedCases: stats.updated,
        errors: stats.errors,
        duration: 0, // 如需記錄耗時，可傳遞
      },
    });
  }

  /**
   * 獲取最新案件
   */
  async getLatestCases(limit: number = 10) {
    return await db.judicaryCase.findMany({
      orderBy: { scrapedAt: "desc" },
      take: limit,
      include: { parties: true },
    });
  }
}

export const caseService = new CaseService();
```

```typescript
    // 5. 保存到數據庫
    const saveResult = await caseService.saveCases(allCases);

    // 6. 記錄爬蟲日誌
    await caseService.logScraperRun("judiciary_hk", "success", {
      total: allCases.length,
      created: saveResult.created,
      updated: saveResult.updated,
    });

    const duration = (Date.now() - startTime) / 1000;
    logger.info(`爬蟲任務完成，耗時 ${duration} 秒`);

    return NextResponse.json({
      success: true,
      data: {
        totalCases: allCases.length,
        newCases: saveResult.created,
        updatedCases: saveResult.updated,
        duration: `${duration}s`,
        timestamp: new Date().toISOString(),
      },
    });
  } catch (error) {
    logger.error(`爬蟲任務失敗: ${error}`);
    
    // 發送到 Sentry
    Sentry.captureException(error, {
      tags: {
        context: "judiciary-scraper",
      },
    });

    // 記錄失敗日誌
    try {
      await caseService.logScraperRun("judiciary_hk", "failed", {
        total: 0,
        created: 0,
        updated: 0,
        errors: error instanceof Error ? error.message : String(error),
      });
    } catch (logError) {
      logger.error(`記錄失敗日誌失敗: ${logError}`);
    }

    return NextResponse.json(
      {
        success: false,
        error: error instanceof Error ? error.message : "Unknown error",
      },
      { status: 500 }
    );
  }
}
```

### 5.2 失敗重試機制

```typescript
// 帶自動重試的爬蟲

async function scrapeWithRetry(
  fn: () => Promise<any>,
  maxRetries: number = 3
): Promise<any> {
  let lastError: Error | null = null;

  for (let attempt = 1; attempt <= maxRetries; attempt++) {
    try {
      return await fn();
    } catch (error) {
      lastError = error as Error;
      logger.warn(`嘗試 ${attempt} 失敗，${5 ** attempt} 秒後重試...`);
      await delay(5 ** attempt * 1000); // 指數退避
    }
  }

  throw lastError;
}
```

```typescript
async function getCasesWithCache(
```
